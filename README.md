# Frank's Money Tracker

A simple, mobile-friendly personal finance tracker.

## Publish with GitHub Pages
1. Upload `index.html`, `manifest.json`, and `sw.js` to the root of your repository.
2. In the repository, open **Settings → Pages**.
3. Under **Build and deployment**, choose **Deploy from a branch**.
4. Choose branch **main** and folder **/(root)**, then Save.
5. Wait for GitHub Pages to publish the site.

Open the published site in Safari on your iPhone. Tap Share → Add to Home Screen.

Entries are stored locally in the browser on your device. Use Download backup regularly. CSV export is available for spreadsheet use.
